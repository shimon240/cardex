# Cardex

Мобильное веб-приложение для изучения иностранных слов.

- **Словарь** — стартовый экран: все сохранённые слова с прогрессом.
- **Добавить** — круглая кнопка «+» справа внизу открывает панель снизу: впиши слово, Grok 4.20 вернёт перевод, транскрипцию, объяснение и примеры. Или «Заполнить вручную»: слово, одно или несколько значений и примеры, без запроса к Grok. Панель закрывается крестиком, тапом по фону или свайпом вниз.
- **Учить** — карточки по системе Лейтнера: рус → иностранный, иностранный → рус или вперемешку. Ответ проверяется локально, а неточные варианты оценивает Grok.
- **Разделы по языкам** — выпадающий список справа вверху, всегда выбран один язык. Раздел появляется сам, когда добавляешь первое слово на новом языке (язык определяет Grok); «+ Новый раздел…» создаёт раздел заранее. Выбранный раздел запоминается, тренировка и словарь показывают только его слова, а русские слова переводятся на его язык.

## Устройство

- Фронтенд: статические `index.html`, `app.js`, `styles.css` (без сборки), хостинг на GitHub Pages. Pages кэширует файлы на 10 минут, поэтому при изменении `app.js` или `styles.css` поднимай `?v=N` в их ссылках в `index.html`, иначе браузер соберёт новую страницу со старым скриптом.
- Данные: Supabase, таблица `public.cards` с RLS (каждый видит только свои карточки).
- Grok: edge-функция `supabase/functions/grok`. Ключ xAI хранится в Supabase Vault (`xai_api_key`) и читается только сервисной ролью через `public.get_xai_key()`.
