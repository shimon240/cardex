# Cardex

Мобильное веб-приложение для изучения иностранных слов.

- **Добавить** — впиши слово, Grok 4.20 вернёт перевод, транскрипцию, объяснение и примеры. Или «Заполнить вручную»: слово, одно или несколько значений и примеры, без запроса к Grok.
- **Учить** — карточки по системе Лейтнера: рус → иностранный, иностранный → рус или вперемешку. Ответ проверяется локально, а неточные варианты оценивает Grok.
- **Словарь** — все сохранённые слова с прогрессом.
- **Разделы по языкам** — полоса сверху: «Все», затем раздел на каждый язык. Раздел появляется сам, когда добавляешь первое слово на новом языке (язык определяет Grok); «+» создаёт раздел заранее. Выбранный раздел запоминается, тренировка и словарь показывают только его слова, а русские слова переводятся на его язык.

## Устройство

- Фронтенд: статические `index.html`, `app.js`, `styles.css` (без сборки), хостинг на GitHub Pages.
- Данные: Supabase, таблица `public.cards` с RLS (каждый видит только свои карточки).
- Grok: edge-функция `supabase/functions/grok`. Ключ xAI хранится в Supabase Vault (`xai_api_key`) и читается только сервисной ролью через `public.get_xai_key()`.
